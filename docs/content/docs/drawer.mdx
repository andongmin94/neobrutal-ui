Use Drawer for a compact task presented from a viewport edge. It is built on Base UI, not Vaul. Use [Sheet](/docs/sheet) for an edge dialog when drawer-specific interaction is unnecessary.

## Usage

```tsx
import { Button } from "@/components/ui/button";
import {
  Drawer,
  DrawerTrigger,
  DrawerContent,
  DrawerHeader,
  DrawerTitle,
  DrawerDescription,
  DrawerFooter,
  DrawerClose,
} from "@/components/ui/drawer";

export default function TaskDrawer() {
  return (
    <Drawer swipeDirection="down">
      <DrawerTrigger render={<Button variant="outline" />}>Task details</DrawerTrigger>
      <DrawerContent>
        <DrawerHeader>
          <DrawerTitle>Task details</DrawerTitle>
          <DrawerDescription>Review this task before returning to the workspace.</DrawerDescription>
        </DrawerHeader>
        <div className="p-4">The draft is ready for review.</div>
        <DrawerFooter>
          <DrawerClose render={<Button variant="outline" />}>Close</DrawerClose>
        </DrawerFooter>
      </DrawerContent>
    </Drawer>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `Drawer.open` / `onOpenChange` | Controlled visibility and close cancellation | Uncontrolled |
| `Drawer.swipeDirection` | Swipe-to-dismiss edge: `up`, `right`, `down`, or `left` | `down` |
| `Drawer.snapPoints` / `snapPoint` | Native snap positions and controlled active snap | — |
| `Drawer.modal` | Focus, scroll, and outside-interaction behavior | `true` |
| `DrawerTrigger.render` / `DrawerClose.render` | Button composition | Primitive elements |
| `DrawerTitle` / `DrawerDescription` | Modal name and explanation | — |
| `DrawerContent` | Styled Base UI viewport, popup, and content | — |

## Accessibility

Provide a title, useful description, and an explicit close action rather than relying only on a drag gesture. Test keyboard focus, Escape, and focus restoration. Long content must scroll within reachable bounds, and the on-screen keyboard must not hide the only action. Do not show successful persistence merely because the drawer closed.
