Use Collapsible for one independent section of optional content. Use [Accordion](/docs/accordion) for a related set of expandable sections. Visibility can be controlled by application state or left uncontrolled.

## Usage

```tsx
import { Button } from "@/components/ui/button";
import { Collapsible, CollapsibleTrigger, CollapsibleContent } from "@/components/ui/collapsible";

export default function AdvancedOptions() {
  return (
    <Collapsible className="grid max-w-sm gap-3">
      <CollapsibleTrigger render={<Button variant="outline" />}>
        Advanced options
      </CollapsibleTrigger>
      <CollapsibleContent>
        <p>Additional workspace preferences belong here.</p>
      </CollapsibleContent>
    </Collapsible>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `open` / `onOpenChange` | Controlled expanded state | Uncontrolled |
| `defaultOpen` | Initial expanded state | `false` |
| `disabled` | Prevent toggling | `false` |
| `CollapsibleTrigger.render` | Button composition | Primitive button |
| `CollapsibleContent.keepMounted` | Preserve closed content DOM | `false` |

## Accessibility

The trigger must describe the content it reveals. Keep it keyboard accessible and do not nest other controls inside it. Enter and Space toggle the panel. Do not hide required instructions or validation errors in a closed section without giving the user a clear way to discover them.
