Use Select for a compact list of predefined options. Give each SelectItem a stable value and display text. For searchable choices use [Combobox](/docs/combobox).

## Usage

```tsx
"use client";
import { useState } from "react";
import {
  Select,
  SelectTrigger,
  SelectValue,
  SelectContent,
  SelectItem,
} from "@/components/ui/select";

const statuses = [
  { value: "draft", label: "Draft" },
  { value: "published", label: "Published" },
];

export default function PublicationStatus() {
  const [status, setStatus] = useState<string | null>("draft");
  return (
    <div className="grid max-w-sm gap-2">
      <label htmlFor="publication-status">Publication status</label>
      <Select items={statuses} value={status} onValueChange={setStatus}>
        <SelectTrigger id="publication-status">
          <SelectValue placeholder="Choose a status" />
        </SelectTrigger>
        <SelectContent>
          {statuses.map((option) => (
            <SelectItem key={option.value} value={option.value}>
              {option.label}
            </SelectItem>
          ))}
        </SelectContent>
      </Select>
      <p role="status">Selected: {status ?? "None"}</p>
    </div>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `Select.value` / `onValueChange` | Controlled string or null selection; receives Base UI event details | Uncontrolled |
| `Select.defaultValue` | Initial selection | Unset |
| `Select.items` | Value-to-label mapping or `{ value, label }` array used by SelectValue to display the selected label | Unset |
| `Select.name` / `required` / `disabled` | Form key and constraints | Unset / false / false |
| `SelectTrigger.size` | `sm` or `default` | `default` |
| `SelectValue.placeholder` | Prompt without selection | Unset |
| `SelectItem.value` / `disabled` | Option value and availability | Value required / false |
| `SelectContent.side` / `align` | Preferred popup placement and alignment | `bottom` / `start` |
| `SelectContent.alignItemWithTrigger` | Align the selected item over the trigger | `false` |
| `SelectContent.alignOffset` / `arrowPadding` / `collisionPadding` | Alignment, arrow, and collision-boundary spacing, in pixels | `0` |
| `SelectContent.sideOffset` | Trigger-to-popup gap, in pixels | `4` |

Pass the same options to `Select.items` and render their `SelectItem` elements, as in the Usage example. `items` supplies the selected display label; it does not render the popup options. Base UI 1.8 does not infer that label from `SelectItem` text. Labels can contain icons and text, and `SelectValue` also accepts a child function for custom display.

## Accessibility

Associate a visible label with the trigger. Keep option text meaningful without color or an icon. Verify arrow navigation, typeahead, Escape, and focus return. Selection is application state; this component does not save it to a server.
