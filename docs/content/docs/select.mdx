Use Select for a compact list of predefined options. Give each SelectItem a stable value and display text. For searchable choices use [Combobox](/docs/combobox).

## Usage

```tsx
"use client";
import { useState } from "react";
import {
  Select,
  SelectTrigger,
  SelectValue,
  SelectContent,
  SelectItem,
} from "@/components/ui/select";

export default function PublicationStatus() {
  const [status, setStatus] = useState("draft");
  return (
    <div className="grid max-w-sm gap-2">
      <label htmlFor="publication-status">Publication status</label>
      <Select value={status} onValueChange={setStatus}>
        <SelectTrigger id="publication-status">
          <SelectValue placeholder="Choose a status" />
        </SelectTrigger>
        <SelectContent>
          <SelectItem value="draft">Draft</SelectItem>
          <SelectItem value="published">Published</SelectItem>
        </SelectContent>
      </Select>
      <p role="status">Selected: {status}</p>
    </div>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `Select.value` / `onValueChange` | Controlled string selection | Uncontrolled |
| `Select.defaultValue` | Initial selection | Unset |
| `Select.name` / `required` / `disabled` | Form key and constraints | Unset / false / false |
| `SelectTrigger.size` | sm or default | `default` |
| `SelectValue.placeholder` | Prompt without selection | Unset |
| `SelectItem.value` / `disabled` | Option value and availability | Value required / false |

## Accessibility

Associate a visible label with the trigger. Keep option text meaningful without color or an icon. Verify arrow navigation, typeahead, Escape, and focus return. Selection is application state; this component does not save it to a server.
