Use Scroll Area when a panel needs its own scrollable content. Set a height or maximum height so there is something to scroll. Do not replace ordinary page scrolling without a clear layout need.

## Usage

```tsx
import { ScrollArea } from "@/components/ui/scroll-area";

export default function ActivityList() {
  return (
    <ScrollArea
      className="h-48 w-full max-w-sm rounded-base border-2 border-border"
      aria-label="Recent activity"
    >
      <ul className="space-y-3 p-4">
        {Array.from({ length: 12 }, (_, index) => (
          <li key={index}>Workspace update {index + 1}</li>
        ))}
      </ul>
    </ScrollArea>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `ScrollArea.className` | Root bounds and layout | Unbounded unless styled |
| `ScrollArea.type` | auto, always, hover, or scroll visibility | `hover` |
| `ScrollArea.scrollHideDelay` | Transient scrollbar hide delay in milliseconds | `600` |
| `ScrollBar.orientation` | Vertical or horizontal scrollbar | `vertical` |
| Children | Content inside the viewport | Required for useful scrolling |

## Accessibility

Ensure keyboard users can reach and scroll the region. Name substantial regions and do not trap wheel or touch scrolling unnecessarily. Horizontal content needs a matching horizontal scrollbar and a clear cue that more content exists.
