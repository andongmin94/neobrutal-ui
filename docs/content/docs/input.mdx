Use Input for short text, email, password, or file entry. It wraps Base UI Input and preserves ordinary input props. Use [Textarea](/docs/textarea) for multi-line text and [Input Group](/docs/input-group) for attached units or actions.

## Usage

```tsx
import { Input } from "@/components/ui/input";

export default function EmailField() {
  return (
    <div className="grid w-full max-w-sm gap-2">
      <label htmlFor="email">Email address</label>
      <Input
        id="email"
        name="email"
        type="email"
        autoComplete="email"
        required
        aria-describedby="email-help"
      />
      <p id="email-help" className="text-sm">
        Used only for workspace invitations.
      </p>
    </div>
  );
}
```

## API reference

| Prop | Purpose | Default |
| --- | --- | --- |
| `type` | Native type such as text, email, password, file | `text` |
| `value` / `onChange` | Controlled value and native event | Uncontrolled |
| `defaultValue` | Initial uncontrolled value | — |
| `id` / `name` | Label association and form key | — |
| `disabled` / `required` / `readOnly` | Native constraints | `false` |
| `aria-invalid` / `aria-describedby` | Invalid state and supporting text | Unset |

## Accessibility

Provide a visible label or justified accessible name. A placeholder is not a label. Match autocomplete and input mode to the task. Do not control the value of a file input. Associate validation feedback with the field and validate submitted data on the server.
