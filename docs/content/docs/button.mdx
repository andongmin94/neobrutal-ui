Use Button for actions such as saving, opening a dialog, or changing state. For navigation, use an anchor or router link styled with `buttonVariants`; do not nest a link inside a button.

## Usage

```tsx
import { Plus } from "lucide-react";
import { Button } from "@/components/ui/button";

export default function Actions() {
  return (
    <div className="flex flex-wrap gap-3">
      <Button type="submit">Save changes</Button>
      <Button variant="outline" type="button">
        Cancel
      </Button>
      <Button size="icon" type="button" aria-label="Add item">
        <Plus aria-hidden="true" />
      </Button>
      <Button disabled aria-busy="true">
        Saving…
      </Button>
    </div>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `variant` | `default`, `outline`, `secondary`, `ghost`, `destructive`, `link`, `noShadow`, `neutral`, `reverse` | `default` |
| `size` | `xs`, `sm`, `default`, `lg`, `icon`, `icon-xs`, `icon-sm`, `icon-lg` | `default` |
| `type` | `button`, `submit`, or `reset` | Base UI default |
| `disabled` | Prevents interaction | `false` |
| `render` | Compose with another button element | Native button |
| `aria-busy` | Communicates pending work; does not disable the control | Unset |

## Accessibility

Name every icon-only button. Set `type="submit"` explicitly for form submission. Enter and Space activate the button. Manage pending state in your application and disable repeated submissions when appropriate. Custom components supplied to `render` must forward props and the ref to their underlying button.

## Navigation and composition

The `link` variant changes appearance only. For a destination, import `buttonVariants` from `@/components/ui/button-variants` and apply it to an anchor or router link. The style function is server-safe. There is no additional `Button asChild` API.

```tsx
import { buttonVariants } from "@/components/ui/button-variants";

<a href="/docs" className={buttonVariants({ variant: "outline" })}>
  Read the guide
</a>;
```
