Use Button for actions such as saving, opening a dialog, or changing state.
For navigation, use an anchor or router link styled with `buttonVariants`; do not put a link inside
a button.

## Usage

```tsx
import { Button } from "@/components/ui/button";

export default function Example() {
  return <Button>Save changes</Button>;
}
```

Start with the normal button above.
Use `variant` to change the appearance and `size` to change the dimensions.
The live preview shows the available styles, icon buttons, disabled states, and loading examples.

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `variant` | `default`, `outline`, `secondary`, `ghost`, `destructive`, `link`, `noShadow`, `neutral`, `reverse` | `default` |
| `size` | `xs`, `sm`, `default`, `lg`, `icon`, `icon-xs`, `icon-sm`, `icon-lg` | `default` |
| `type` | `button`, `submit`, or `reset` | Base UI default |
| `disabled` | Prevents interaction | `false` |
| `render` | Uses another button element while preserving behavior | Native button |
| `aria-busy` | Announces pending work; it does not disable the control | Unset |

## Accessibility

Give every icon-only button an accessible name with `aria-label`.
Set `type="submit"` explicitly for form submission.
Enter and Space activate the button.
Manage pending state in your application and disable repeated submissions when appropriate.
A custom element supplied to `render` must forward its props and ref to the underlying button.

## Navigation and composition

The `link` variant changes appearance only.
For a destination, import `buttonVariants` and apply it to an anchor or router link:

```tsx
import { buttonVariants } from "@/components/ui/button-variants";

<a href="/docs" className={buttonVariants({ variant: "outline" })}>
  Read the guide
</a>;
```
