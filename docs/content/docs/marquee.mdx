Use Marquee for non-essential decorative text. It is a default export accepting short strings, not a general-purpose carousel. Keep important information available without movement.

## Installation

Complete the [base setup](/docs/installation). The CLI includes this item's animation styles. For manual installation:

<Installation component="marquee">

Create **`components/ui/marquee.tsx`**:

<include cwd lang="tsx">
  ./src/components/ui/marquee.tsx
</include>

Also add this item's animation definitions to your Tailwind CSS stylesheet:

```css
@theme inline {
  --animate-marquee: marquee 5s linear infinite;
  --animate-marquee2: marquee2 5s linear infinite;
  @keyframes marquee {
    from { transform: translateX(0%); }
    to { transform: translateX(-100%); }
  }
  @keyframes marquee2 {
    from { transform: translateX(100%); }
    to { transform: translateX(0%); }
  }
}
```
</Installation>

## Usage

```tsx
import Marquee from "@/components/ui/marquee";

export default function FeatureStrip() {
  return (
    <Marquee
      items={[
        "Source you own",
        "Hard shadows",
        "Clear interactions",
        "Light and dark",
        "Build your way",
        "React components",
      ]}
    />
  );
}
```

## API reference

| Prop / behavior | Purpose | Default |
| --- | --- | --- |
| `items` | Short unique text strings | Required |
| Pause / Resume | Stops or resumes both animation strips | Running |
| Reduced motion | Disables decorative movement | User preference respected |
| Duplicate strip | Repeated visual content | Hidden from assistive technology |

## Accessibility

Keep strings unique because they are used as React keys. The native Pause/Resume button is keyboard accessible and stops both strips together. Reduced-motion preferences disable animation and hide the redundant second strip. Do not put essential instructions or controls inside moving content. Supply enough items to cover the available width without gaps.
