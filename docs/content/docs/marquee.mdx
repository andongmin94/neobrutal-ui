## Installation

The CLI installation includes the animation tokens and keyframes automatically.

<Installation component="marquee">

<include cwd lang="tsx">
  ./src/components/ui/marquee.tsx
</include>

When installing manually, also add these animation tokens and keyframes inside your
`@theme inline` block:

```css
--animate-marquee: marquee 5s linear infinite;
--animate-marquee2: marquee2 5s linear infinite;

@keyframes marquee {
  0% {
    transform: translateX(0%);
  }
  100% {
    transform: translateX(-100%);
  }
}

@keyframes marquee2 {
  0% {
    transform: translateX(100%);
  }
  100% {
    transform: translateX(0%);
  }
}
```

</Installation>

Make sure there is enough content in items so it loops perfectly.

Visit <a target="_blank" href="https://jackwhiting.co.uk/posts/creating-a-marquee-with-tailwind-css">this article</a> to learn more.

## Usage

```ts
import Marquee from "@/components/ui/marquee";
```

```ts
const items = ["Item 1", "Item 2", "Item 3", "Item 4", "Item 5"];
```

```tsx
<Marquee items={items} />
```
