Use Marquee for non-essential decorative text. It is a default export accepting short strings, not a general-purpose carousel. Keep important information available without movement.

## Usage

```tsx
import Marquee from "@/components/ui/marquee";

export default function FeatureStrip() {
  return (
    <Marquee
      items={[
        "Source you own",
        "Hard shadows",
        "Clear interactions",
        "Light and dark",
        "Build your way",
        "React components",
      ]}
    />
  );
}
```

## API reference

| Prop / behavior | Purpose | Default |
| --- | --- | --- |
| `items` | Short unique text strings | Required |
| Pause / Resume | Stops or resumes the repeating track | Running |
| Reduced motion | Disables decorative movement | User preference respected |
| Duplicate strip | Repeated visual content | Hidden from assistive technology |

## Accessibility

Keep strings unique because they are used as React keys. The native Pause/Resume button is keyboard accessible and stops the repeating track. Reduced-motion preferences disable animation, hide the redundant copy, and wrap the original text. Each copy spans at least the available width, even with only a few items. The track follows the reading direction. Do not put essential instructions or controls inside moving content.
