## API reference

This editable recipe has no required props. Change the constants in the installed source to connect application data.

| Source / control | Purpose |
| --- | --- |
| `releases` | Ordered release labels with nonnegative install and update counts. |
| `config` | Series labels and shared-theme colors. |
| Activity measure | Counts or shares, with matching vertical-axis units. |
| Release period | All six releases or the latest three. |
| View activity data | Exact counts and per-release update shares. |

For dynamic data, handle an empty array or zero totals before calculating shares. Do not interpret repeat events as unique users. Normalized areas show composition, not absolute volume; tooltips retain the original event counts.

## Accessibility

Both controls have visible labels and native keyboard behavior. Solid and dashed boundaries distinguish the two series in addition to color. The text summary and table provide the values without requiring hover. The chart has a definite height, an accessible figure label, and no entrance animation.
