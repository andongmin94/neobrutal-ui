Compare a team's plan with completed work across four sprints. Switch to signed variance to see the difference around zero. Counts describe sample work items, not their size, quality, or team productivity.

## API reference

The component has no required props. Adapt the installed source rather than configuring an extra chart abstraction.

| Source / control | Purpose |
| --- | --- |
| `teams` | Paired planned and delivered counts for each sprint. |
| `config` | Labels and shared-theme colors. |
| Delivery team | Product or Platform sample data. |
| Delivery view | Paired bars or signed delivered-minus-planned values. |
| View delivery data | Exact values for the selected team. |

The comparison view starts at zero. Variance uses a symmetric scale around zero. Update the fixed domains when replacing the sample data; both views must contain the full data range. Variance is a count, not a percentage.

## Accessibility

Controls have visible labels. Planned bars are outlined and dashed; delivered bars are filled and solid. Negative values are identified by position and signed table values, not just color. A visible summary and exact table remain available in either view. Plot animations are disabled.
