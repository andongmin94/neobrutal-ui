Use Popover for contextual controls that do not need a full-screen interruption. PopoverContent includes positioning and a portal. Use [Dialog](/docs/dialog) for a longer focused task.

## Usage

```tsx
import { Button } from "@/components/ui/button";
import {
  Popover,
  PopoverTrigger,
  PopoverContent,
  PopoverTitle,
  PopoverDescription,
} from "@/components/ui/popover";

export default function HelpPopover() {
  return (
    <Popover>
      <PopoverTrigger render={<Button variant="outline" />}>Sharing help</PopoverTrigger>
      <PopoverContent>
        <PopoverTitle>Workspace sharing</PopoverTitle>
        <PopoverDescription>Only invited members can open this workspace.</PopoverDescription>
        <a href="/docs" className="underline">
          Read the guide
        </a>
      </PopoverContent>
    </Popover>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `Popover.open` / `onOpenChange` | Controlled visibility | Uncontrolled |
| `Popover.defaultOpen` | Initial visibility | `false` |
| `PopoverTrigger.render` | Trigger button composition | Primitive button |
| `PopoverContent.side` / `align` | Preferred placement | `bottom` / `center` |
| `PopoverContent.sideOffset` | Trigger-to-popup gap | `4` |
| `PopoverContent.initialFocus` / `finalFocus` | Focus destinations | Base UI behavior |

## Accessibility

Name the popup with PopoverTitle and explain its purpose when needed. Keep controls reachable and verify Escape dismissal and focus return. Do not move essential instructions into a popup users must discover before they can complete a form.
