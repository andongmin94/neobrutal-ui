Use Radio Group when one choice must be selected from a short visible set. Each item needs a unique value and its own label. Use [Select](/docs/select) when space is limited or the list is longer.

## Usage

```tsx
"use client";
import { useId } from "react";
import { RadioGroup, RadioGroupItem } from "@/components/ui/radio-group";
import { Label } from "@/components/ui/label";

export default function DeliveryPreference() {
  const labelId = useId();
  return (
    <fieldset className="grid gap-3">
      <legend id={labelId} className="mb-3">Delivery frequency</legend>
      <RadioGroup aria-labelledby={labelId} defaultValue="weekly" name="frequency">
        <div className="flex items-center gap-2">
          <RadioGroupItem value="daily" id="daily" />
          <Label htmlFor="daily">Daily</Label>
        </div>
        <div className="flex items-center gap-2">
          <RadioGroupItem value="weekly" id="weekly" />
          <Label htmlFor="weekly">Weekly</Label>
        </div>
      </RadioGroup>
    </fieldset>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `RadioGroup.value` / `onValueChange` | Controlled selection | Uncontrolled |
| `RadioGroup.defaultValue` | Initial choice | Unset |
| `RadioGroup.name` | Form submission key | Unset |
| `RadioGroup.disabled` / `readOnly` / `required` | Group constraints | `false` |
| `RadioGroup.form` / `inputRef` | Native form association | — |
| `RadioGroupItem.value` / `id` | Unique option and label target | Value required |

## Accessibility

Give `RadioGroup` an accessible name with `aria-labelledby` or `aria-label`. When using a native fieldset and legend, explicitly connect the inner radio group to the legend with `aria-labelledby`, as shown above. Label each item; its value is not a visible description. Arrow keys change the focused selection. Do not simulate a mutually exclusive choice with independent checkboxes.
