Use Radio Group when one choice must be selected from a short visible set. Each item needs a unique value and its own label. Use [Select](/docs/select) when space is limited or the list is longer.

## Usage

```tsx
import { RadioGroup, RadioGroupItem } from "@/components/ui/radio-group";
import { Label } from "@/components/ui/label";

export default function DeliveryPreference() {
  return (
    <fieldset className="grid gap-3">
      <legend className="mb-3">Delivery frequency</legend>
      <RadioGroup defaultValue="weekly" name="frequency">
        <div className="flex items-center gap-2">
          <RadioGroupItem value="daily" id="daily" />
          <Label htmlFor="daily">Daily</Label>
        </div>
        <div className="flex items-center gap-2">
          <RadioGroupItem value="weekly" id="weekly" />
          <Label htmlFor="weekly">Weekly</Label>
        </div>
      </RadioGroup>
    </fieldset>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `RadioGroup.value` / `onValueChange` | Controlled selection | Uncontrolled |
| `RadioGroup.defaultValue` | Initial choice | Unset |
| `RadioGroup.name` | Form submission key | Unset |
| `RadioGroup.disabled` / `required` | Group constraints | `false` |
| `RadioGroup.orientation` | Keyboard orientation | Upstream behavior |
| `RadioGroupItem.value` / `id` | Unique option and label target | Value required |

## Accessibility

Use a fieldset and legend or an accessible group name. Label each item; its value is not a visible description. Arrow keys change the focused selection. Do not simulate a mutually exclusive choice with independent checkboxes.
