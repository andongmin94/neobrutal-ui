## Built with

- [shadcn](https://ui.shadcn.com/) provides the registry schema and source distribution workflow.
- [Base UI](https://base-ui.com/react) provides accessible, unstyled behavior for interactive
  primitives.
- [Tailwind CSS](https://tailwindcss.com/) provides the styling layer and token mapping.
