## Maintenance

neobrutal-ui is maintained by [andongmin94](https://github.com/andongmin94). The registry and
documentation are developed as separate projects and deployed together from the same repository.

## Upstream project

This project is derived from [ekmas/neobrutalism-components](https://github.com/ekmas/neobrutalism-components),
created by Samuel Breznjak.

The remake keeps the neobrutalist component direction while maintaining a separate registry,
Base UI implementations, current shadcn integration, new templates, and rewritten
documentation.

## Related projects

- [shadcn](https://ui.shadcn.com/) provides the registry schema and source distribution workflow.
- [Base UI](https://base-ui.com/react) provides accessible, unstyled behavior for interactive
  primitives.
- [Tailwind CSS](https://tailwindcss.com/) provides the styling layer and token mapping.
