Use Carousel for a short sequence that benefits from horizontal or vertical browsing. Do not hide essential information exclusively in later slides. Leave room for navigation buttons positioned outside the track.

## Usage

```tsx
import {
  Carousel,
  CarouselContent,
  CarouselItem,
  CarouselNext,
  CarouselPrevious,
} from "@/components/ui/carousel";

export default function Highlights() {
  return (
    <div className="px-12">
      <Carousel className="w-full max-w-sm" aria-label="Project highlights">
        <CarouselContent>
          {["Plan", "Build", "Review"].map((title) => (
            <CarouselItem key={title}>
              <div className="border-2 border-border p-8">{title}</div>
            </CarouselItem>
          ))}
        </CarouselContent>
        <CarouselPrevious />
        <CarouselNext />
      </Carousel>
    </div>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `orientation` | `horizontal` or `vertical` | `horizontal` |
| `opts` | Embla options such as `align` and `loop` | Embla defaults |
| `plugins` | Explicitly installed Embla plugins | None |
| `setApi` | Receives the Embla API | — |
| `CarouselContent` / `CarouselItem` | Track and slides | — |
| `CarouselPrevious` / `CarouselNext` | Boundary-aware navigation buttons | Icon buttons |
| `CarouselPrevious.variant` / `size` | Previous button appearance and size | `noShadow` / `icon` |
| `CarouselNext.variant` / `size` | Next button appearance and size | `noShadow` / `icon` |

## Accessibility

Name the carousel region and provide meaningful slide content. Keep navigation buttons available for people who cannot swipe. Autoplay is not included; adding it requires pause controls and reduced-motion support. Give a vertical carousel a definite height and test the layout on narrow screens.

Left and right arrow shortcuts apply when the carousel region or its navigation buttons have focus. Add `tabIndex={0}` to make the region focusable. Inputs and other controls inside a slide keep their own keyboard behavior.

Navigation buttons accept state-based `className` functions. Their `onClick` handlers run before scrolling; call `event.preventDefault()` to cancel that button's navigation.
