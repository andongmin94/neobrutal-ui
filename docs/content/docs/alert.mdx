Use Alert for a message that belongs in the page: a failed save, permission notice, or service warning. It does not open a modal or dismiss itself. Use [Sonner](/docs/sonner) for transient feedback.

## Usage

```tsx
import { Alert, AlertDescription, AlertTitle } from "@/components/ui/alert";

export default function SaveError() {
  return (
    <Alert variant="destructive">
      <AlertTitle>Changes were not saved</AlertTitle>
      <AlertDescription>Check your connection, then try saving again.</AlertDescription>
    </Alert>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `variant` | `default` or `destructive` | `default` |
| `AlertTitle` | Short summary | — |
| `AlertDescription` | Explanation or recovery steps | — |
| `children` | Icon, text, and optional actions | — |
| `role` | Announcement semantics | `alert` |
| `className` | Layout and width overrides | — |

## Accessibility

The default alert role announces important updates. Do not use it for every decorative card. For non-urgent updates, choose `role="status"` or ordinary page text as appropriate. Use words, not color alone, to explain severity. Hide decorative icons with `aria-hidden`.
