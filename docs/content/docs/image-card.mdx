Use Image Card when an image and its caption form one piece of content. It is a default export. The caption also supplies the image alternative text, so use a meaningful description rather than a filename.

## Usage

```tsx
import ImageCard from "@/components/ui/image-card";

export default function WorkspaceImage() {
  return (
    <ImageCard
      imageUrl="/images/workspace.jpg"
      caption="The shared studio workspace"
      className="w-full max-w-sm"
    />
  );
}
```

Add your own `/images/workspace.jpg` asset. The component neither uploads nor optimizes images.

## API reference

| Prop | Purpose | Default |
| --- | --- | --- |
| `imageUrl` | Image URL or application asset | Required |
| `caption` | Visible caption and image alternative text | Required |
| `className` | Figure width and layout | Width 250px |

## Accessibility

Choose a caption explaining the image. This component does not expose independent alt text or a decorative-image mode; adapt the copied source when those semantics are needed. The image fills a 4:3 area using object-cover, so verify that cropping preserves the important subject. Keep the original source asset accessible and provide a useful fallback in applications that load remote images.
