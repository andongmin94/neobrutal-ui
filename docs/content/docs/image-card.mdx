Use Image Card when an image and its caption form one piece of content. It is a default export. Provide independent alternative text and a visible caption so their purposes are not conflated.

## Usage

```tsx
import ImageCard from "@/components/ui/image-card";

export default function WorkspaceImage() {
  return (
    <ImageCard
      imageUrl="/images/workspace.jpg"
      alt="Desks and monitors arranged around the shared studio"
      caption="The shared studio workspace"
      className="w-full max-w-sm"
    />
  );
}
```

Add your own `/images/workspace.jpg` asset. The component neither uploads nor optimizes images.

## API reference

| Prop | Purpose | Default |
| --- | --- | --- |
| `imageUrl` | Image URL or application asset | Required |
| `alt` | Alternative text for the image, or an empty string for decorative content | Required |
| `caption` | Visible caption | Required |
| `className` | Figure width and layout | Width 250px, constrained to the available width |

## Accessibility

Use alt text to communicate the image's relevant information. Provide an empty alt when the image is decorative or its information is fully conveyed by nearby text. The visible caption can supply context without repeating the alternative text. The image fills a 4:3 area using object-cover, so verify that cropping preserves the important subject. Keep the original source asset accessible and provide a useful fallback in applications that load remote images.
