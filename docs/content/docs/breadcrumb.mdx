Use Breadcrumb when the page belongs to a meaningful hierarchy. Parent levels are links; the current page is a non-interactive label. It is not a replacement for primary navigation or browser history.

## Usage

```tsx
import {
  Breadcrumb,
  BreadcrumbList,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@/components/ui/breadcrumb";

export default function DocumentationTrail() {
  return (
    <Breadcrumb>
      <BreadcrumbList>
        <BreadcrumbItem>
          <BreadcrumbLink href="/">Home</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbLink href="/docs">Documentation</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbPage>Components</BreadcrumbPage>
        </BreadcrumbItem>
      </BreadcrumbList>
    </Breadcrumb>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `Breadcrumb` | Navigation landmark and native nav props | Labelled breadcrumb |
| `BreadcrumbList` / `BreadcrumbItem` | Ordered trail and steps | — |
| `BreadcrumbLink.href` / `render` | Destination or router-link composition | Anchor |
| `BreadcrumbPage` | Current non-interactive page | `aria-current="page"` |
| `BreadcrumbSeparator` | Decorative divider | Chevron |
| `BreadcrumbEllipsis` | Visual omitted-level indicator | Not a menu button |

## Accessibility

Use descriptive link text and mark only the current page. Separators are decorative. An ellipsis alone does not reveal hidden levels: compose a real menu trigger when users need to open the omitted trail. On narrow screens allow wrapping rather than hiding the current page.
