Use this recipe when users need to search a list before selecting one option. It combines existing components rather than exposing a standalone Combobox registry endpoint. Adapt the options and selection state to your application.

## Installation

Complete the [base setup](/docs/installation), then install [Button](/docs/button), [Popover](/docs/popover), and [Command](/docs/command). Copy the Usage recipe into your application.

```bash
npx shadcn@latest add https://neobrutal-ui.andongmin.com/r/button.json https://neobrutal-ui.andongmin.com/r/popover.json https://neobrutal-ui.andongmin.com/r/command.json
```

## Usage

```tsx
"use client";
import { useState } from "react";
import { Button } from "@/components/ui/button";
import {
  Command,
  CommandEmpty,
  CommandInput,
  CommandItem,
  CommandList,
} from "@/components/ui/command";
import { Popover, PopoverContent, PopoverTrigger } from "@/components/ui/popover";

const options = ["React", "Vue", "Svelte"];

export default function FrameworkPicker() {
  const [open, setOpen] = useState(false);
  const [value, setValue] = useState("");
  return (
    <Popover open={open} onOpenChange={setOpen}>
      <PopoverTrigger
        render={
          <Button variant="outline" role="combobox" aria-expanded={open} aria-label="Framework" />
        }
      >
        {value || "Choose framework"}
      </PopoverTrigger>
      <PopoverContent className="w-64 p-0">
        <Command>
          <CommandInput placeholder="Search frameworks…" aria-label="Search frameworks" />
          <CommandList>
            <CommandEmpty>No framework found.</CommandEmpty>
            {options.map((option) => (
              <CommandItem
                key={option}
                value={option}
                onSelect={() => {
                  setValue(option);
                  setOpen(false);
                }}
              >
                {option}
              </CommandItem>
            ))}
          </CommandList>
        </Command>
      </PopoverContent>
    </Popover>
  );
}
```

## API reference

| Recipe state / part | Purpose | Default |
| --- | --- | --- |
| `open` / `setOpen` | Popover visibility | `false` |
| `value` / `setValue` | Selected option | Empty string |
| `CommandInput` | Filters the list | Empty query |
| `CommandItem.value` | Searchable option identity | Explicit in this recipe |
| `CommandItem.onSelect` | Save selection and close | Application callback |
| `CommandEmpty` | No-match feedback | — |

## Accessibility

Name the selection control and search field. Keep the current selection visible in the trigger. Verify keyboard opening, list navigation, selection, dismissal, and focus return. Do not use a searchable popup for unrestricted free-text entry; this recipe selects from a predefined list. For server search, add loading and error states and disable client filtering when the server owns results.
