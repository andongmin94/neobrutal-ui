Use Badge for a short status or category, not a primary action. This implementation supports two variants. For a destination, the `render` element must contain the visible content.

## Usage

```tsx
import { Badge } from "@/components/ui/badge";

export default function ProjectBadges() {
  return (
    <div className="flex flex-wrap gap-2">
      <Badge>Published</Badge>
      <Badge variant="neutral">Documentation</Badge>
      <Badge render={<a href="/docs">Read the guide</a>} />
    </div>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `variant` | `default` or `neutral` | `default` |
| `children` | Short visible label | — |
| `render` | Element containing the badge content | `span` |
| `className` | Sizing and layout | — |

## Accessibility

Use readable status text rather than color alone. A decorative badge need not be focusable. An interactive badge must use a real link or button and retain a meaningful accessible name. For dynamically changing status, announce the relevant update in a suitable live region rather than marking every static badge as an alert.
