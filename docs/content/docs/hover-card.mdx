Use Hover Card to preview the destination or entity behind a link. Keep the link useful without the card. Use [Popover](/docs/popover) for an explicit interactive popup and [Tooltip](/docs/tooltip) for a very short hint.

## Usage

```tsx
import { HoverCard, HoverCardContent, HoverCardTrigger } from "@/components/ui/hover-card";

export default function DocumentationPreview() {
  return (
    <HoverCard>
      <HoverCardTrigger href="/docs" className="underline">
        Read the documentation
      </HoverCardTrigger>
      <HoverCardContent>
        <p>Installation steps, component examples, and theme guidance.</p>
      </HoverCardContent>
    </HoverCard>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `HoverCard.open` / `onOpenChange` | Controlled preview visibility | Uncontrolled |
| `HoverCardTrigger.href` / `render` | Link destination or composition | Anchor |
| `HoverCardContent.side` / `align` | Preferred placement | Wrapper positioning |
| `HoverCardContent.sideOffset` | Trigger-to-card gap | `4` |
| `HoverCardContent.className` | Width and layout | Styled surface |

## Accessibility

Do not place required instructions or the only copy of an action inside hover-only content. Touch and keyboard interactions differ from hover, so provide an explicit alternative when opening the content matters. Use descriptive link text and avoid duplicate essential announcements for decorative preview text.
