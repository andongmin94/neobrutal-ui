Use Table for tabular data with headers and related rows. It includes an overflow wrapper, but sorting, filtering, pagination, and selection are not built in. Use [Data Table](/docs/data-table) as a starting point for those behaviors.

## Usage

```tsx
import {
  Table,
  TableCaption,
  TableHeader,
  TableBody,
  TableRow,
  TableHead,
  TableCell,
} from "@/components/ui/table";

export default function InvoiceTable() {
  return (
    <Table>
      <TableCaption>Recent workspace invoices</TableCaption>
      <TableHeader>
        <TableRow>
          <TableHead scope="col">Invoice</TableHead>
          <TableHead scope="col">Status</TableHead>
          <TableHead scope="col" className="text-right">
            Amount
          </TableHead>
        </TableRow>
      </TableHeader>
      <TableBody>
        <TableRow>
          <TableCell>INV-001</TableCell>
          <TableCell>Paid</TableCell>
          <TableCell className="text-right">$120.00</TableCell>
        </TableRow>
      </TableBody>
    </Table>
  );
}
```

## API reference

| Part | Purpose | Default |
| --- | --- | --- |
| `Table` | Native table in horizontal overflow wrapper | Full width |
| `TableHeader` / `TableBody` / `TableFooter` | thead, tbody, tfoot | Semantic elements |
| `TableRow` | Row of cells | tr |
| `TableHead` / `TableCell` | Header/data cell; native scope, colSpan, rowSpan | th / td |
| `TableCaption` | Accessible visible table description | caption |

## Accessibility

Provide a caption or accessible name and appropriate header scopes. Align numbers consistently. Do not replace semantic cells with generic divs or make rows click-only controls. On mobile, keep the scroll region reachable without overflowing the whole page.
