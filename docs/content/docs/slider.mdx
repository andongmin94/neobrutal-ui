Use Slider for an approximate numeric setting with a meaningful range. This wrapper takes arrays even for one thumb. For exact amounts, provide a synchronized numeric input in your application.

## Usage

```tsx
"use client";
import { useState } from "react";
import { Slider } from "@/components/ui/slider";

export default function VolumeSetting() {
  const [volume, setVolume] = useState([50]);
  return (
    <div className="grid max-w-sm gap-3">
      <p>Volume: {volume[0]}%</p>
      <Slider
        value={volume}
        onValueChange={setVolume}
        min={0}
        max={100}
        step={5}
        getAriaLabel={() => "Volume"}
      />
    </div>
  );
}
```

## API reference

| Prop | Purpose | Default |
| --- | --- | --- |
| `value` / `onValueChange` | Controlled numeric array | Uncontrolled |
| `defaultValue` | Initial thumb values | Wrapper default |
| `min` / `max` / `step` | Range and step | 0 / 100 / 1 |
| `orientation` | Horizontal or vertical layout | `horizontal` |
| `getAriaLabel` | Name for each thumb index | Unset |
| `disabled` | Prevent adjustment | `false` |
| `minStepsBetweenThumbs` | Minimum thumb separation | `0` |

## Accessibility

Name each thumb, especially for minimum/maximum ranges. Show values and units in text. Test arrows, Home, and End, and keep pointer targets usable. Run expensive work at the end of interaction rather than on every drag update.
