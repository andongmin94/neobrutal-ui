## API reference

The default export is an editable recipe with no required props. It includes illustrative data,
not a live data connection. Edit the following constants in the installed source to adapt it.

| Source setting | Meaning |
| --- | --- |
| `samples` | Seven daily `[p50, p95]` pairs per service, measured in milliseconds. |
| `days` | Labels matching the sample order. |
| `budget` | The daily p95 threshold, initially 300 milliseconds. |
| `service` | Initially selected service. |
| `config` | Series labels, shared colors, and the contrasting p95 color. |

The summary reports the worst daily p95, not a pooled weekly percentile. A day is over budget only when p95 is strictly greater than the threshold. When changing the budget or data range, update the displayed budget labels and Y-axis domain together.

## Accessibility

The selector has a visible label and supports keyboard input. The chart enables Recharts keyboard
navigation. Calculated summaries remain visible without hovering, and the expandable data table
provides the exact values behind the plot. Preserve these alternatives when adapting the recipe.
The plot does not animate and inherits the consuming project's light and dark theme tokens.
