Use an accordion when readers need to scan several related sections and expand only the details they need. Use [Collapsible](/docs/collapsible) for one independent disclosure. Each item needs a stable, unique `value`.

## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion";

export default function HelpSections() {
  return (
    <Accordion className="w-full">
      <AccordionItem value="source">
        <AccordionTrigger>Can I edit the source?</AccordionTrigger>
        <AccordionContent>Yes. Installed files belong to your application.</AccordionContent>
      </AccordionItem>
      <AccordionItem value="theme">
        <AccordionTrigger>Does it support dark mode?</AccordionTrigger>
        <AccordionContent>Use the matching light and dark theme tokens.</AccordionContent>
      </AccordionItem>
    </Accordion>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `value` / `defaultValue` | Controlled or initial open item values | Uncontrolled |
| `onValueChange` | Receives the next open item values and event details | — |
| `multiple` | Allow more than one item to stay open | `false` |
| `loopFocus` | Wrap keyboard focus between triggers | `true` |
| `orientation` | Keyboard navigation axis | `vertical` |
| `AccordionItem.disabled` | Disables the section | `false` |
| `AccordionContent.keepMounted` | Retains closed panel DOM | `false` |

## Accessibility

Write the section name in `AccordionTrigger`; it is a button inside a heading. Enter and Space toggle an item. Arrow keys move between triggers; Home and End reach the first and last enabled triggers. Do not nest another button or link inside the trigger. In controlled mode, treat the value as the array of currently open item values.
