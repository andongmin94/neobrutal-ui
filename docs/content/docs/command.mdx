Use Command for searchable actions or destinations. CommandDialog combines the list with a dialog, while Command can be embedded in a popover or panel. Shortcut annotations do not register keyboard handlers.

## Usage

```tsx
"use client";
import { useState } from "react";
import {
  Command,
  CommandInput,
  CommandList,
  CommandEmpty,
  CommandGroup,
  CommandItem,
} from "@/components/ui/command";

export default function WorkspaceCommands() {
  const [message, setMessage] = useState("No command selected.");
  return (
    <div className="grid gap-3">
      <Command className="max-w-sm rounded-base border-2 border-border">
        <CommandInput placeholder="Find an action…" aria-label="Find an action" />
        <CommandList>
          <CommandEmpty>No matching command.</CommandEmpty>
          <CommandGroup heading="Workspace">
            <CommandItem value="new-draft" onSelect={() => setMessage("Created a local draft.")}>
              New draft
            </CommandItem>
            <CommandItem disabled>Export workspace</CommandItem>
          </CommandGroup>
        </CommandList>
      </Command>
      <p role="status">{message}</p>
    </div>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `Command.shouldFilter` | Built-in client filtering | `true` |
| `CommandInput.value` / `onValueChange` | Controlled query | Uncontrolled |
| `CommandItem.value` / `keywords` | Search identity and extra terms | Derived label if omitted |
| `CommandItem.onSelect` / `disabled` | Action and availability | — / `false` |
| `CommandGroup.heading` | Related-action label | — |
| `CommandDialog.open` / `onOpenChange` | Dialog visibility | Uncontrolled |
| `CommandShortcut` | Visual annotation | No event handler |

## Accessibility

Label the search field and provide useful no-results feedback. Arrow keys navigate enabled items; Enter chooses an item. Keep action labels meaningful and register real keyboard shortcuts separately. For a command dialog, verify Escape and focus return. Use loading and failure feedback for remote searches rather than presenting an empty result as success.
