Use Sheet for navigation, filters, or an auxiliary task needing more room than a popover. It uses dialog semantics and includes a portal and backdrop. Use [Drawer](/docs/drawer) when drawer interaction fits the task better.

## Usage

```tsx
import { Button } from "@/components/ui/button";
import {
  Sheet,
  SheetTrigger,
  SheetContent,
  SheetHeader,
  SheetTitle,
  SheetDescription,
} from "@/components/ui/sheet";

export default function WorkspacePanel() {
  return (
    <Sheet>
      <SheetTrigger render={<Button variant="outline" />}>Workspace details</SheetTrigger>
      <SheetContent side="right">
        <SheetHeader>
          <SheetTitle>Workspace details</SheetTitle>
          <SheetDescription>Settings shared with all project members.</SheetDescription>
        </SheetHeader>
        <div className="p-4">
          <p>Connect your application settings here.</p>
        </div>
      </SheetContent>
    </Sheet>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `Sheet.open` / `onOpenChange` | Controlled visibility | Uncontrolled |
| `Sheet.defaultOpen` | Initial visibility | `false` |
| `SheetTrigger.render` / `SheetClose.render` | Button composition | Primitive button |
| `SheetContent.side` | top, right, bottom, left | `right` |
| `SheetContent.showCloseButton` | Built-in close control | `true` |
| `SheetContent.initialFocus` / `finalFocus` | Focus destinations | Base UI behavior |

## Accessibility

Provide SheetTitle and a useful description. Keep the close control reachable when content scrolls. Test Escape and focus return. Avoid essential actions below an unreachable mobile viewport. Removing the default close button requires another clear dismissal action.
