## Requirements

You need a React 19 project with Tailwind CSS v4 and shadcn initialized.
UI components work with Next.js and Vite.
Page templates target the Next.js App Router.

Run this from your project folder if shadcn is not initialized yet:

```bash
npx shadcn@latest init
```

Choose **Base UI** if the CLI asks which component library to use.

## Fastest setup

Install the shared base once, then add a component.
Direct URLs work without editing `components.json`.

```bash
npx shadcn@latest add https://neobrutal-ui.andongmin.com/r/neobrutal-ui.json
npx shadcn@latest add https://neobrutal-ui.andongmin.com/r/button.json
```

The base provides the colors, borders, shadows, utilities, and global styles used by every
neobrutal-ui component.

## Check that it works

Render the installed button in one of your pages:

```tsx
import { Button } from "@/components/ui/button";

export default function Example() {
  return <Button>Click me</Button>;
}
```

A button with a bold border and hard shadow means the setup worked.
You can now browse the [component directory](/) and install the pieces you need.

## Existing projects

The shared base changes project-wide styles, so commit your current work before adding it to an
existing application.
Inspect the files first when you need to review the changes:

```bash
npx shadcn@latest view https://neobrutal-ui.andongmin.com/r/neobrutal-ui.json
```

Pay particular attention to global CSS, `components.json`, dependencies, and `lib/utils.ts`.
Individual components do not reinstall the base; they expect those shared styles to exist.

## Add more components

Each component page includes a copyable install command.
For example:

```bash
npx shadcn@latest add https://neobrutal-ui.andongmin.com/r/dialog.json
npx shadcn@latest add https://neobrutal-ui.andongmin.com/r/card.json
```

The CLI installs required packages and supporting components automatically.

## Choose a theme

The shared base starts with yellow.
Install one named theme when you want to replace the project-wide light and dark colors:

```bash
npx shadcn@latest add https://neobrutal-ui.andongmin.com/r/theme-red.json
```

Install one theme at a time rather than adding every preset together.

## Optional: shorter commands

Direct URLs are the simplest starting point.
To use shorter commands such as `@neobrutal-ui/dialog`, merge this entry into the existing
`registries` object in `components.json`:

```json
{
  "registries": {
    "@neobrutal-ui": "https://neobrutal-ui.andongmin.com/r/{name}.json"
  }
}
```

You can then install the same items with shorter names:

```bash
npx shadcn@latest add @neobrutal-ui/dialog
npx shadcn@latest add @neobrutal-ui/theme-red
```

## Templates

Templates install Next.js App Router pages and supporting components.
Inspect their target files before adding one to a project that already uses the same routes.

```bash
npx shadcn@latest view https://neobrutal-ui.andongmin.com/r/blog-template.json
npx shadcn@latest add https://neobrutal-ui.andongmin.com/r/blog-template.json
```

## Manual installation and updates

The **Manual** tab on each component page shows the source files and packages required for that
component.
The installed files belong to your application and are not updated automatically.
Review proposed changes before overwriting files that you have customized:

```bash
npx shadcn@latest add https://neobrutal-ui.andongmin.com/r/button.json --dry-run
```
