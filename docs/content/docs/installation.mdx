## Requirements

You need a React 19 project with Tailwind CSS v4 and shadcn initialized.
UI components work with Next.js and Vite.
Page templates target the Next.js App Router.

Run this from your project folder if shadcn is not initialized yet:

```bash
npx shadcn@latest init
```

Choose **Base UI** if the CLI asks which component library to use.

## Fastest setup

Install the shared base once, then add your first component.
`@neobrutal-ui` is listed in the [official shadcn directory](https://ui.shadcn.com/docs/directory).
The CLI resolves its address automatically; no separate registry registration is needed.

```bash
npx shadcn@latest add @neobrutal-ui/neobrutal-ui
npx shadcn@latest add @neobrutal-ui/button
```

If `shadcn init` created a default `button.tsx`, answer **Yes** when the CLI asks to overwrite it.
Without replacing that file, you may still see the default shadcn button with the new colors.
If you've customized your Button, answer **No** and review its diff before replacing it.
The `--dry-run` command in [Manual installation and updates](#manual-installation-and-updates)
shows the proposed changes without applying them.

The base provides the colors, borders, shadows, utilities, and global styles used by every
neobrutal-ui component.

## Check that it works

Render the installed button in one of your pages:

```tsx
import { Button } from "@/components/ui/button";

export default function Example() {
  return <Button>Click me</Button>;
}
```

A button with a bold border and hard shadow means the setup worked.
You can now browse the [component directory](/) and install the pieces you need.

## Existing projects

The shared base changes project-wide styles, so commit your current work before adding it to an
existing application. Inspect its changes first:

```bash
npx shadcn@latest view @neobrutal-ui/neobrutal-ui
```

Pay particular attention to global CSS, `components.json`, dependencies, and your utilities.
Component, recipe, and template modules use your configured aliases. Explicit page routes
still install into the Next.js App Router. Compositions do not reinstall the base theme.

## Add more components

Each component page includes a copyable install command. For example:

```bash
npx shadcn@latest add @neobrutal-ui/dialog
npx shadcn@latest add @neobrutal-ui/card
```

The CLI installs required packages and supporting components automatically.
When the CLI asks to replace an existing component, review the proposed changes before
accepting so you can keep your customizations.

## Choose a theme

The shared base starts with **Mono**. Light mode uses cool-white surfaces and graphite
actions; dark mode uses cool-charcoal surfaces and pale-silver actions. Chart series retain muted
colors instead of becoming indistinguishable shades of gray.

No extra theme command is needed for this default. Install one named theme to use a colorful
palette instead:

```bash
npx shadcn@latest add @neobrutal-ui/theme-red
```

Use `@neobrutal-ui/theme-mono` in the same command to return to the default palette.
Install one theme at a time rather than adding every preset together. Both light and dark
tokens are included; your application's theme toggle selects the mode with the `.dark` class.

## Registry addresses

The official namespace works without manually editing `components.json`.
You can also install with the public item URL:

```bash
npx shadcn@latest add https://neobrutal-ui.andongmin.com/r/dialog.json
```

For a fork or local registry, configure that endpoint in your project's `registries` map
while keeping your current aliases and other settings.

## Templates

Templates install Next.js App Router pages and supporting components.
Inspect their target files before adding one to a project that already uses the same routes.

```bash
npx shadcn@latest view @neobrutal-ui/blog-template
npx shadcn@latest add @neobrutal-ui/blog-template
```

## Manual installation and updates

The **Manual** tab shows the source files and required packages.
Installed files belong to your application and are not updated automatically.
Check the [release notes](https://github.com/andongmin94/neobrutal-ui/releases), then review proposed
changes before overwriting files that you have customized:

```bash
npx shadcn@latest add @neobrutal-ui/button --dry-run
```
