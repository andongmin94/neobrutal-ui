Use Context Menu for commands associated with an object or region. A context menu must not be the only way to discover an essential action. Offer an ordinary button or menu for touch users and people unfamiliar with right-click behavior.

## Usage

```tsx
"use client";
import { useRef, useState } from "react";
import {
  ContextMenu,
  ContextMenuTrigger,
  ContextMenuContent,
  ContextMenuItem,
} from "@/components/ui/context-menu";

export default function FileCommands() {
  const triggerRef = useRef<HTMLDivElement>(null);
  const [message, setMessage] = useState("No action selected.");
  return (
    <div className="grid gap-3">
      <ContextMenu>
        <ContextMenuTrigger
          ref={triggerRef}
          className="block rounded-base border-2 border-dashed border-border p-8"
          tabIndex={0}
        >
          Right-click this file or press Shift+F10.
        </ContextMenuTrigger>
        <ContextMenuContent finalFocus={triggerRef}>
          <ContextMenuItem onClick={() => setMessage("Duplicate selected in this preview.")}>
            Duplicate
          </ContextMenuItem>
          <ContextMenuItem disabled>Move to archive</ContextMenuItem>
        </ContextMenuContent>
      </ContextMenu>
      <p role="status">{message}</p>
    </div>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `ContextMenu` | Root state and callbacks | Closed |
| `ContextMenuTrigger` | Target region and render composition | Primitive trigger |
| `ContextMenuContent` | Positioned menu surface | Primitive-managed |
| `ContextMenuContent.finalFocus` | Element ref, function, or boolean controlling focus after close | Trigger or previously focused element |
| `ContextMenuItem.onClick` / `disabled` | Action and availability | — / `false` |
| `ContextMenuCheckboxItem` / `ContextMenuRadioGroup` | Stateful choices | Controlled or uncontrolled |
| `ContextMenuSub` | Nested commands | — |
| `ContextMenuContent.side` / `align` | Preferred popup placement and alignment | `right` / `start` |
| `ContextMenuContent.alignOffset` / `sideOffset` | Alignment adjustment and trigger gap, in pixels | `4` / `0` |
| `ContextMenuContent.arrowPadding` / `collisionPadding` | Arrow and collision-boundary spacing, in pixels | `0` |
| `ContextMenuItem.variant` | Item appearance: `default` or `destructive` | `default` |
| `ContextMenuCheckboxItem.closeOnClick` / `ContextMenuRadioItem.closeOnClick` | Close after selecting a stateful item | `true` |

## Accessibility

Make the relevant target keyboard reachable when it needs keyboard context-menu access. Test Shift+F10, arrow navigation, and Escape. Keep another discoverable route to essential commands. Avoid unexpectedly replacing the browser's context menu across the entire page.

Menu content is bounded by Base UI's available height. Long menus scroll so pointer users and keyboard users can reach every item.

Right-clicking does not focus the target in every browser. When closing the menu should return focus to its target, pass that target's ref to `ContextMenuContent.finalFocus`, as in the example. Base UI handles the focus return.
