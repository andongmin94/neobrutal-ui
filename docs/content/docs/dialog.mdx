Use Dialog for a focused task that interrupts the current page. Use [Alert Dialog](/docs/alert-dialog) for consequential confirmation. DialogContent includes the portal and backdrop; do not add a second modal wrapper.

## Installation

Complete the [base setup](/docs/installation). For manual installation:

<Installation component="dialog">

```bash
npm install @base-ui/react@^1.8.0
```

Also install [Button](/docs/button), then create **`components/ui/dialog.tsx`**:

<include cwd lang="tsx">
  ./src/components/ui/dialog.tsx
</include>
</Installation>

The live profile form additionally uses Input and Label. Its local save does not send a request. In an application, close only after an asynchronous operation succeeds and keep the dialog open on failure.

## Usage

```tsx
import { Button } from "@/components/ui/button";
import {
  Dialog,
  DialogTrigger,
  DialogContent,
  DialogHeader,
  DialogTitle,
  DialogDescription,
} from "@/components/ui/dialog";

export default function WorkspaceDialog() {
  return (
    <Dialog>
      <DialogTrigger render={<Button />}>Workspace settings</DialogTrigger>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>Workspace settings</DialogTitle>
          <DialogDescription>Update preferences shared with your team.</DialogDescription>
        </DialogHeader>
        <p>Place the task controls here.</p>
      </DialogContent>
    </Dialog>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `Dialog.open` / `onOpenChange` | Controlled visibility | Uncontrolled |
| `Dialog.defaultOpen` | Initial visibility | `false` |
| `DialogContent.showCloseButton` | Built-in close control | `true` |
| `DialogContent.initialFocus` / `finalFocus` | Focus destinations | Base UI behavior |
| `DialogTrigger.render` / `DialogClose.render` | Compose with a button | Primitive element |

## Accessibility

Keep a meaningful title and description. Tab and Shift+Tab stay in the modal; Escape closes a dismissible dialog. Verify that focus returns to its trigger. Do not remove the close control without providing another clear dismissal action. For longer tasks, keep actions reachable while the content scrolls.
