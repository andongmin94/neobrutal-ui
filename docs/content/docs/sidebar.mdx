## Installation

Complete the [base setup](/docs/installation). The CLI installs both files and dependencies. For manual installation:

<Installation component="sidebar">

```bash
npm install @base-ui/react@^1.8.0
```

Also install [Avatar](/docs/avatar), [Collapsible](/docs/collapsible), [Dropdown Menu](/docs/dropdown-menu), [Button](/docs/button), [Sheet](/docs/sheet), and [Tooltip](/docs/tooltip).

Create **`components/ui/sidebar.tsx`**:

<include cwd lang="tsx">
  ./src/components/ui/sidebar.tsx
</include>

Create **`hooks/use-mobile.ts`**:

<include cwd lang="ts">
  ./src/hooks/use-mobile.ts
</include>
</Installation>

The default keyboard toggle is Ctrl+B or Command+B. Check for conflicts with your application shortcuts.

The complete live preview additionally uses [Breadcrumb](/docs/breadcrumb). Install it before copying the Code example, then save both `page.tsx` and `_sidebar.tsx` from that tab in the same directory. Its workspace metrics are illustrative, and the avatar uses initials so no image asset is required. Replace the sample navigation destinations with your application's routes.

```bash
npx shadcn@latest add https://neobrutal-ui.andongmin.com/r/breadcrumb.json
```

## Usage

```tsx
import {
  SidebarProvider,
  Sidebar,
  SidebarContent,
  SidebarGroup,
  SidebarGroupLabel,
  SidebarGroupContent,
  SidebarMenu,
  SidebarMenuItem,
  SidebarMenuButton,
  SidebarInset,
  SidebarTrigger,
} from "@/components/ui/sidebar";

export default function ApplicationLayout() {
  return (
    <SidebarProvider>
      <Sidebar>
        <SidebarContent>
          <SidebarGroup>
            <SidebarGroupLabel>Workspace</SidebarGroupLabel>
            <SidebarGroupContent>
              <nav aria-label="Workspace navigation">
                <SidebarMenu>
                  <SidebarMenuItem>
                    <SidebarMenuButton render={<a href="/docs">Documentation</a>} />
                  </SidebarMenuItem>
                </SidebarMenu>
              </nav>
            </SidebarGroupContent>
          </SidebarGroup>
        </SidebarContent>
      </Sidebar>
      <SidebarInset>
        <header className="p-4">
          <SidebarTrigger />
        </header>
        <section className="p-4">
          <h1>Workspace overview</h1>
        </section>
      </SidebarInset>
    </SidebarProvider>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `SidebarProvider.defaultOpen` | Initial desktop expanded state | `true` |
| `SidebarProvider.open` / `onOpenChange` | Controlled desktop state | Uncontrolled |
| `Sidebar.side` | `left` or `right` | `left` |
| `Sidebar.variant` | `sidebar`, `floating`, or `inset` | `sidebar` |
| `Sidebar.collapsible` | `offcanvas`, `icon`, or `none` | `offcanvas` |
| `SidebarTrigger` / `useSidebar` | Toggle and context access | Provider required |
| `SidebarMenuButton.isActive` | Active link styling | `false` |
| `SidebarMenuButton.variant` | Menu button appearance: `default` or `outline` | `default` |
| `SidebarMenuButton.size` | Menu button size: `default`, `sm`, or `lg` | `default` |
| `SidebarMenuAction.showOnHover` | Reveal the action on hover or keyboard focus | `false` |
| `SidebarMenuSubButton.size` | Nested link size: `sm` or `md` | `md` |
| `SidebarMenuSubButton.isActive` | Active nested-link styling | `false` |

## Accessibility

Name navigation regions and give links destinations and readable labels. Collapsed icon-only items still need names. The mobile version behaves as a modal sheet; check focus and scroll at both sizes. Persistence is application-owned. Initialize `defaultOpen` or control `open` / `onOpenChange` from your own storage; the component does not write cookies.

In desktop offcanvas mode, collapsed navigation is hidden from keyboard focus and assistive technology. Keep a SidebarTrigger outside the sidebar so it can be reopened. SidebarRail remains available for pointer users.

`onOpenChange` also observes changes when `open` is uncontrolled. Trigger and rail click handlers run before toggling and can cancel it with `event.preventDefault()`. A disabled `SidebarMenuButton` stays disabled when it has a tooltip.
