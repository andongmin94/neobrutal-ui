## Installation

Complete the [base setup](/docs/installation). The CLI installs both files and dependencies. For manual installation:

<Installation component="sidebar">

```bash
npm install @base-ui/react@^1.6.0
```

Also install [Avatar](/docs/avatar), [Collapsible](/docs/collapsible), [Dropdown Menu](/docs/dropdown-menu), [Button](/docs/button), [Input](/docs/input), [Sheet](/docs/sheet), [Skeleton](/docs/skeleton), [Tooltip](/docs/tooltip), and [Separator](/docs/separator).

Create **`components/ui/sidebar.tsx`**:

</include>

Create **`hooks/use-mobile.ts`**:

<include cwd lang="ts">

The default keyboard toggle is Ctrl+B or Command+B. Check for conflicts with your application shortcuts.

## Usage

```tsx
import {
  SidebarProvider,
  Sidebar,
  SidebarContent,
  SidebarGroup,
  SidebarGroupLabel,
  SidebarGroupContent,
  SidebarMenu,
  SidebarMenuItem,
  SidebarMenuButton,
  SidebarInset,
  SidebarTrigger,
} from "@/components/ui/sidebar";

export default function ApplicationLayout() {
  return (
    <SidebarProvider>
      <Sidebar>
        <SidebarContent>
          <SidebarGroup>
            <SidebarGroupLabel>Workspace</SidebarGroupLabel>
            <SidebarGroupContent>
              <nav aria-label="Workspace navigation">
                <SidebarMenu>
                  <SidebarMenuItem>
                    <SidebarMenuButton render={<a href="/docs" />}>Documentation</SidebarMenuButton>
                  </SidebarMenuItem>
                </SidebarMenu>
              </nav>
            </SidebarGroupContent>
          </SidebarGroup>
        </SidebarContent>
      </Sidebar>
      <SidebarInset>
        <header className="p-4">
          <SidebarTrigger />
        </header>
        <section className="p-4">
          <h1>Workspace overview</h1>
        </section>
      </SidebarInset>
    </SidebarProvider>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `SidebarProvider.defaultOpen` | Initial desktop expanded state | `true` |
| `SidebarProvider.open` / `onOpenChange` | Controlled desktop state | Uncontrolled |
| `Sidebar.side` | left or right | `left` |
| `Sidebar.variant` | sidebar, floating, or inset | `sidebar` |
| `Sidebar.collapsible` | offcanvas, icon, or none | `offcanvas` |
| `SidebarTrigger` / `useSidebar` | Toggle and context access | Provider required |
| `SidebarMenuButton.isActive` | Active link styling | `false` |

## Accessibility

Name navigation regions and give links destinations and readable labels. Collapsed icon-only items still need names. The mobile version behaves as a modal sheet; check focus and scroll at both sizes. Persistence requires the application to read the sidebar cookie and supply initial state.
