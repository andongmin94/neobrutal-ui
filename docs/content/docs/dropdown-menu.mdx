Use Dropdown Menu for commands associated with a button. Use [Select](/docs/select) for a form value. A menu item runs an application action; opening the menu does not fetch or save data.

## Usage

```tsx
"use client";
import { useState } from "react";
import { Button } from "@/components/ui/button";
import {
  DropdownMenu,
  DropdownMenuTrigger,
  DropdownMenuContent,
  DropdownMenuItem,
} from "@/components/ui/dropdown-menu";

export default function ProjectActions() {
  const [message, setMessage] = useState("No action selected.");
  return (
    <div className="grid gap-3">
      <DropdownMenu>
        <DropdownMenuTrigger render={<Button variant="outline" />}>
          Project actions
        </DropdownMenuTrigger>
        <DropdownMenuContent>
          <DropdownMenuItem onClick={() => setMessage("Rename selected in this preview.")}>
            Rename
          </DropdownMenuItem>
          <DropdownMenuItem disabled>Export</DropdownMenuItem>
        </DropdownMenuContent>
      </DropdownMenu>
      <p role="status">{message}</p>
    </div>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `DropdownMenu.open` / `onOpenChange` | Controlled visibility | Uncontrolled |
| `DropdownMenuTrigger.render` | Compose the trigger button | Primitive button |
| `DropdownMenuContent.side` / `align` | Popup position | `bottom` / `center` |
| `DropdownMenuItem.onClick` / `disabled` | Action and availability | — / `false` |
| `DropdownMenuCheckboxItem.checked` / `onCheckedChange` | Independent checked state | Uncontrolled |
| `DropdownMenuRadioGroup.value` / `onValueChange` | Mutually exclusive choice | Uncontrolled |
| `DropdownMenuSub` | Nested menu | — |

## Accessibility

Use an explicit trigger name and clear action labels. Arrow keys navigate items, Enter selects, and Escape dismisses. Displayed shortcut text does not implement a shortcut. For destructive actions, describe the consequence and use confirmation when warranted. Do not turn a menu into a complex form with unrelated focusable controls.
