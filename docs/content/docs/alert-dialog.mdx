Use Alert Dialog before a consequential operation. Use [Dialog](/docs/dialog) for ordinary editing. Explain the actual consequence instead of asking only “Are you sure?”.

## Usage

```tsx
import { Button } from "@/components/ui/button";
import {
  AlertDialog,
  AlertDialogAction,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogTitle,
  AlertDialogTrigger,
} from "@/components/ui/alert-dialog";

export default function ConfirmArchive({ onArchive }: { onArchive: () => void }) {
  return (
    <AlertDialog>
      <AlertDialogTrigger render={<Button variant="outline" />}>Archive project</AlertDialogTrigger>
      <AlertDialogContent>
        <AlertDialogHeader>
          <AlertDialogTitle>Archive this project?</AlertDialogTitle>
          <AlertDialogDescription>
            The project will leave the active list. You can restore it later.
          </AlertDialogDescription>
        </AlertDialogHeader>
        <AlertDialogFooter>
          <AlertDialogCancel>Keep project</AlertDialogCancel>
          <AlertDialogAction onClick={onArchive}>Archive project</AlertDialogAction>
        </AlertDialogFooter>
      </AlertDialogContent>
    </AlertDialog>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `AlertDialog.open` / `onOpenChange` | Controlled modal state | Uncontrolled |
| `AlertDialog.defaultOpen` | Initial visibility | `false` |
| `AlertDialogTrigger.render` | Compose a trigger button | Primitive button |
| `AlertDialogTitle` / `AlertDialogDescription` | Accessible name and consequence | — |
| `AlertDialogCancel` | Cancel and restore focus | Styled close button |
| `AlertDialogAction` | Confirm and close | Styled close button |

## Accessibility

Keep a meaningful title and description. The modal traps keyboard focus and normally returns focus to its trigger. Cancel must be easy to identify. Closing the dialog does not prove that a server operation succeeded: for asynchronous work, control `open`, show failure inside the dialog, and close only after success.
