Use Progress when work is ongoing. It renders its track and indicator for you. Pass a number when completed work can be measured; pass null when it cannot.

## Usage

```tsx
import { Progress } from "@/components/ui/progress";

export default function UploadProgress() {
  return (
    <div className="grid max-w-sm gap-2">
      <p id="upload-label">Uploading files: 42%</p>
      <Progress value={42} aria-labelledby="upload-label" />
    </div>
  );
}
```

## API reference

| Prop | Purpose | Default |
| --- | --- | --- |
| `value` | Completed amount; null means indeterminate | `null` |
| `max` | Maximum amount | `100` |
| `aria-label` / `aria-labelledby` | Accessible operation name | Unset |
| `getAriaValueText` | Meaningful value announcement | Base UI behavior |
| `className` | Width and root layout | Full available width |

## Accessibility

Name the operation, not just the control. Do not invent percentages for unknown work. Keep values in range and announce completion or failure separately; reaching 100 does not prove that an application operation succeeded.
