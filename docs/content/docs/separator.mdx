Use Separator sparingly to clarify a boundary. It renders the Base UI separator primitive; it is not a heading and does not name either side of the content.

## Usage

```tsx
import { Separator } from "@/components/ui/separator";

export default function SectionDivider() {
  return (
    <div className="grid max-w-sm gap-4">
      <h2 className="font-bold">Workspace</h2>
      <p>Shared project settings.</p>
      <Separator aria-hidden="true" />
      <p>Members can manage their own notifications.</p>
    </div>
  );
}
```

## API reference

| Prop | Purpose | Default |
| --- | --- | --- |
| `orientation` | horizontal or vertical | `horizontal` |
| `className` | Length, spacing, and layout | Theme border color |
| `aria-hidden` | Hide a decorative divider from assistive technology | Unset |
| `render` | Primitive element composition | Separator primitive |

## Accessibility

Hide purely decorative dividers from assistive technology. Give vertical separators a parent with a defined height. Use headings and spacing for document structure rather than placing a separator between every sentence.
