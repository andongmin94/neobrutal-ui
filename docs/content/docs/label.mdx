Use Label to name an input, checkbox, switch, or select trigger. It renders a native label and does not create a field, validation state, or layout by itself.

## Usage

```tsx
import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";

export default function DisplayName() {
  return (
    <div className="grid max-w-sm gap-2">
      <Label htmlFor="display-name">Display name</Label>
      <Input id="display-name" name="displayName" autoComplete="nickname" />
    </div>
  );
}
```

## API reference

| Prop | Purpose | Default |
| --- | --- | --- |
| `htmlFor` | Associated control ID | Unset |
| `children` | Visible field name | — |
| `className` | Typography and layout | Theme styling |
| Native label props | Standard HTML attributes | Forwarded |

## Accessibility

Match htmlFor to a unique control ID. Keep the label visible while the user types. Use a fieldset and legend to name a set of related controls. Do not put unrelated links or buttons inside a label, and do not substitute placeholder text for an actual field name.
