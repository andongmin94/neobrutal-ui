Use Resizable for workspaces, inspectors, and editors. Give the group a bounded size and each panel a useful minimum. The wrappers use the current react-resizable-panels API directly: numeric sizes are pixels; use explicit strings such as `"35%"` for percentages.

## Usage

```tsx
import { ResizablePanelGroup, ResizablePanel, ResizableHandle } from "@/components/ui/resizable";

export default function SplitWorkspace() {
  return (
    <ResizablePanelGroup
      orientation="horizontal"
      className="min-h-48 rounded-base border-2 border-border"
    >
      <ResizablePanel defaultSize="35%" minSize="20%">
        <div className="p-4">Files</div>
      </ResizablePanel>
      <ResizableHandle withHandle aria-label="Resize file panel" />
      <ResizablePanel defaultSize="65%" minSize="30%">
        <div className="p-4">Editor</div>
      </ResizablePanel>
    </ResizablePanelGroup>
  );
}
```

## API reference

| Prop / part | Purpose | Default |
| --- | --- | --- |
| `ResizablePanelGroup.orientation` | Split direction | `horizontal` |
| `ResizablePanel.defaultSize` | Initial size; number = pixels, `"35%"` = percentage | Distributed by group |
| `ResizablePanel.minSize` / `maxSize` | Resize constraints in the same units | Upstream defaults |
| `ResizablePanel.collapsible` | Allow collapse | `false` |
| `ResizablePanel.panelRef` | Native panel imperative handle | Unset |
| `ResizablePanelGroup.groupRef` | Native group imperative handle | Unset |
| `ResizablePanelGroup.onLayoutChanged` | Receive the native layout after resizing | Unset |
| `ResizableHandle.withHandle` | Display a grip | `false` |
| `ResizableHandle.disabled` | Prevent adjustment | `false` |

For persisted layouts, use `useDefaultLayout` from react-resizable-panels and pass its returned layout properties to the group. The wrappers do not implement a second storage system, translate callbacks, or reinterpret native size units.

## Accessibility

Name separators meaningfully. Keep controls usable at the smallest panel size and test keyboard resizing as well as dragging. Set an explicit height for vertical layouts. Use responsive CSS when a split workspace is unsuitable for narrow screens; resizing alone is not a mobile layout.
